**Type:** task
**Status:** resolved
**Blocked by:** 10

## Goal

按用户提供的参考图重做功能开关页的宫格卡片：名称 + 开关、Key + 复制 + 默认返回值、分隔线、环境/状态/更新时间四层结构。卡片改为白色无描边 + 柔和阴影，字号与间距按参考图还原。页面外壳（标题、统计、工具栏、白色面板）、表格视图、环境配色、状态文案与分页策略保持不变。

同时修复宫格视图首屏加载时会先渲染“暂无 Flag”空态、缺少 Loading 反馈的问题（SPEC 第 260 条要求列表拉取必须有加载反馈）。

## Answer

**改动**

- `frontend/src/pages/FlagListPage.tsx`：宫格卡片重写为四层结构；新增复制按钮与默认值胶囊；开关与复制按钮拦截冒泡；Enter / Space 进入详情；首次加载骨架卡与刷新降透明度；分页默认值与选项改为 12 / 24 / 48。
- `frontend/src/styles/prototype.css`：重写 `.flag-grid` / `.flag-card` 区块；新增阴影卡片、Key 行、复制按钮、竖线、胶囊、横线与 44×24 开关覆写。
- `frontend/src/pages/FlagListPage.replica.test.tsx`：卡片结构用例覆盖四层信息与复制/默认值；新增首次拉取骨架用例；`beforeEach` 固定默认视图。
- 后端沿用上一轮的 `FlagRepository.Touch` 与规则同步时间刷新，测试见 `rule_service_test.go`。

**已知偏差**

- 参考图卡片约 405px 宽；当前 3 列网格在 1536 视口给出约 386px、1440 视口约 354px。386 下 Key 完整，1440 下 Key 会省略 1–2 个字符（带 title 提示）。
- 为使整行在约 386px 内放下，Key 由图中的 14px 收到 13px，复制图标与胶囊内边距相应收紧。
- 标题与开关之间不保留参考图中的大空隙，改用标准 CSS 省略号。
- 环境色与状态文案按用户先前决定保持现状，不采用参考图的高饱和蓝/红。
