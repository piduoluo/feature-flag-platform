# 24: 统一界面字体

Type: task
Status: resolved

## Goal

以功能开关页顶部「全部环境 / Development」的字体为基准，统一界面字体与字重，保留标题、正文和辅助信息的字号层级。

## Acceptance

- 页面、Ant Design 控件及浮层、Key、规则值、评估输入与结果使用同一字体栈。
- 常规文字、强调文字与标题保留层级，字重收敛到 400 / 500 / 600。
- JSON 输入与高亮层保持一致，桌面和手机无整页横向溢出。
- 生产构建、现有前端测试和真实页面检查通过；更新本地前端服务。

## Scope

仅改排版，覆盖 SPEC 中列表、详情、规则配置、评估与审计界面（US 4–6、9、24–31），不改业务逻辑或数据。

## Answer

- 以浏览器实测顶部环境筛选的 Ant Design 字体栈建立 `--font-ui`，由全局样式与 ConfigProvider 共用；Key、代码标签、规则值、JSON 输入/高亮及结果统一使用该字体。
- 字重统一为 400 / 500 / 600；详情标题沿用主题半粗体，保留原有字号、布局、颜色与业务交互。
- `npm run build`、Docker 前端构建通过；原有大包体积警告仍存在。
- `npm test -- --maxWorkers=2 --minWorkers=1`：14 个文件、130 项测试全部通过；保留已有 React act 警告。
- 真实浏览器检查了列表/宫格、详情、评估与全局操作历史；展开审计记录正常，JSON 输入和高亮层的字体/字号/字重/行高/字距一致。
- 更新本地前端容器后，在 localhost:3000 对四个页面分别以 1440px 和 390px 宽度检查：可见文字均为一套字体、字重仅 400/500/600，无整页横向溢出。
- 截图位于 `output/playwright/typography-*.png`；`git diff --check` 通过。
