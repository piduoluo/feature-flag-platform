# 11: Flag 详情单 URL 与来源感知返回

**Type:** task
**Status:** resolved
**Blocked by:** 10

## Goal

把 Flag 详情的三个 Tab 收敛到同一个规范 URL，Tab 只作为页面内部状态存在；在详情页左上角增加来源感知的返回导航，让用户能够回到实际进入详情前的页面，而不是在多个 Tab URL 之间后退。

## Acceptance

- [x] Flag 详情的规范 URL 为 `/flags/:id`，切换「规则配置」「变更历史」「基本设置」不改变 URL，也不新增浏览器历史记录。
- [x] 旧入口 `/flags/:id?tab=audit|settings|rules` 仍可打开对应 Tab，并以 `replace` 规范回 `/flags/:id`，不产生额外历史记录。
- [x] 旧路由 `/flags/:id/:tab` 兼容跳转到同一规范 URL，并保留首次打开的目标 Tab。
- [x] 详情页左上角显示返回导航，按实际来源显示「功能开关」「全局操作历史」或「规则评估」。
- [x] 从功能开关列表进入时，返回列表保留环境、搜索和分页；列表 `page` / `page_size` 进入 URL。
- [x] 从全局操作历史进入时直接打开变更历史，返回时回到全局操作历史；从评估页进入详情时，返回导航指回评估页。
- [x] 直接打开详情时没有来源信息，返回导航兜底回功能开关列表，标签为「功能开关」；刷新时沿用浏览器保留的来源记录。
- [x] 未保存草稿在 Tab 之间切换时保留在输入框/规则列表中，且不触发离开提示。
- [x] 真正离开详情页时仍由 `useBlocker` 拦截，刷新/关页仍由 `beforeunload` 提醒。
- [x] 后端、数据库、API 与业务规则不变。
- [x] TypeScript、前端测试、生产构建和真实浏览器冒烟测试通过。

## Answer

详情页的 Tab 已从路由状态改为组件状态，所有入口最终只落到 `/flags/:id`。

**URL 与兼容**

- 规范地址：`/flags/:id`。
- `?tab=...` 与 `/flags/:id/:tab` 都是「一次性入口」：读取目标 Tab 后用 `replace` 清理为规范地址，因此浏览历史中只有一条详情记录。
- 全局操作历史仍指向 `/flags/:id?tab=audit`，点击后打开变更历史，地址立即归一；旧书签仍可用。
- 全局操作历史旧链接中的 `from` / `fromLabel` 在清理 query 时通过 `setSearchParams(..., { state })` 保留，避免返回导航丢失来源。

**左上角返回**

- 新增 `DetailBackNav`，只在 Flag 详情这类有明确上级的页面显示。
- 所有进入详情的站内入口都通过 `location.state` 传入完整来源地址与来源名称：
  - 功能开关列表 → `功能开关`，来源 URL 含环境、搜索和分页；
  - 全局操作历史 → `全局操作历史`；
  - 评估控制台「返回 Flag 详情」→ `规则评估`。
- 返回时优先历史回退；直接打开等没有历史来源的场景兜底跳转来源 URL 或 `/flags`。

**列表状态**

- `page`、`page_size` 进入列表 URL，和环境、搜索、启停状态一起由服务端/分页驱动。
- 从详情返回时恢复原筛选和页码，而不是回到列表第一页。

**草稿与拦截**

- Tab 切换不再触发路由导航，因此不会触发 `useBlocker`；基本设置和规则草稿继续保存在 `basicDraft` / `rulesDraft`，切回 Tab 后原样恢复。
- 只有真正离开 `/flags/:id` 时才拦截；`beforeunload` 行为保持不变。

**已知取舍**

- 因为 Tab 不再进入 URL，刷新规范地址会回到默认的「规则配置」。直接打开带 Tab 的旧地址时仍会先打开目标 Tab，然后 URL 归一。
- 全局操作历史自身的筛选条件仍是页面本地状态，本次只保证返回该页面；若需要连同审计筛选一起恢复，需要单独把审计筛选 URL 化。

**验证**

- 后端无改动。
- 前端：`tsc --noEmit`、`vite build` 通过；13 个测试文件共 114 项测试通过。
- Playwright：10 项真实浏览器冒烟测试通过，覆盖单 URL 的 Tab 切换、浏览器返回列表、旧 query/path 深链接归一、来源列表返回保留筛选，以及从全局审计进入变更历史。
- 手工真实浏览器验证：列表（含 `page=2`）、全局操作历史、评估控制台三种来源的返回标签与目标地址均正确。
