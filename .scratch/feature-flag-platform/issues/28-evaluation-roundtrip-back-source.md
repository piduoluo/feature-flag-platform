# 28: 在线评估往返详情保留原始返回来源

Type: task
Status: resolved

## Goal

修复从 Flag 详情页进入在线评估控制台后，经「返回 Flag 详情」回到同一详情页时，左上角返回导航被覆盖为「规则评估」、并在两个页面之间无限循环的问题。往返后必须仍能一键回到进入详情前的真实来源页。

## Reproduction

1. 从功能开关列表点击某个 Flag 进入 `/flags/:id`，左上角返回导航显示「功能开关」。
2. 点击「前往在线评估」进入 `/evaluations?flag_key=...&environment=...`。
3. 点击评估页横幅的「返回 Flag 详情」。
4. 详情页左上角变成「规则评估」；点击它回到评估页，再点横幅又回到详情页，来回循环，无法通过左上角返回列表。

## Root cause

- 详情页 `goEvaluate` 只把评估参数写进 URL，没有携带「本次评估由该详情页打开」的标记。
- 评估页无法区分「从该详情页进入」和「从列表/审计页/深链进入」，横幅总是 push 一条新的详情历史记录，并把 location state 覆盖成 `{ from: '/evaluations?...', fromLabel: '规则评估' }`。
- 详情页返回逻辑在从评估页进入时执行 `navigate(-1)`，回到评估页；评估页横幅又 push 回详情页，两条历史记录互相指向，形成循环。

## Acceptance

- [x] 从功能开关列表进入详情 → 前往在线评估 → 返回 Flag 详情：复用原详情历史记录（POP），返回导航仍显示原来源「功能开关」，不再显示「规则评估」。
- [x] 点击该返回导航回到原列表地址，保留环境、搜索和分页参数，不再回到评估页。
- [x] 从全局操作历史进入详情后的同样往返保留「全局操作历史」，返回后回到 `/audit-logs`。
- [x] 从列表行内「在线评估」等非详情入口进入评估页时，仍按原契约 push 详情并显示「规则评估」来源。
- [x] 在评估页切换 Flag 或环境后，横幅返回当前 Flag 详情，而不是跳回进入时的旧详情。
- [x] Cmd/Ctrl/Shift/Alt 或中键点击横幅仍作为普通链接在新标签打开详情，不被返回逻辑拦截。
- [x] 前端单测、类型检查、生产构建通过；真实浏览器回归通过。

## Answer

**导航契约**

新增共享模块 `frontend/src/navigation.ts`：

- `NavSourceState { from, fromLabel }`：详情页的原始来源，用于左上角返回导航。
- `EvaluationEntryState { fromFlagDetail: { path } }`：评估页的进入上下文，只在由详情页的「前往在线评估」打开时携带。
- `readNavSource` / `isInAppPath`：对 location state 中的来源路径做站内校验，避免把外部地址当作返回目标。

**详情页**

- `goEvaluate` 在跳转 `/evaluations` 时携带 `{ fromFlagDetail: { path: '/flags/:id' } }`；查询参数、Tab 内部状态和已有的未保存草稿处理均不变。
- 左上角来源统一通过 `readNavSource(location.state)` 读取，行为与原先一致。

**评估页横幅**

- 当携带 `fromFlagDetail` 且当前 Flag Key / 环境仍与进入时一致：横幅渲染为指向该详情路径的链接，普通左键点击调用 `navigate(-1)` 回到**已存在的**详情历史记录。POP 会原样恢复详情页的原始 `NavSourceState`，因此左上角继续显示「功能开关」或「全局操作历史」，再点一次即可回到真实来源页。
- 当用户在评估页切换了 Flag 或环境（`unchangedEntry` 为 false）：保留原有正向导航语义，push 当前 Flag 的详情并写入 `{ from: 当前评估页地址, fromLabel: '规则评估' }`，避免莫名跳回旧 Flag。
- 带修饰键或中键的点击直接放行，保留浏览器原生「新标签页打开」行为。

**历史栈效果**

修复前：`列表(0) → 详情(1) → 评估(2) → 详情(3,来源被覆盖为规则评估)`，详情(3) 的返回执行 `navigate(-1)` 回到评估(2)，评估横幅又 push 详情，形成循环。

修复后：`列表(0) → 详情(1) → 评估(2)`，横幅执行 POP 回到详情(1)，原始来源与历史索引均未改变，左上角 `navigate(-1)` 直接回到列表(0)。

**验证**

- 前端单测：14 个文件 148 项全部通过，新增 3 项：
  - 详情页往返后 `historyAction === 'POP'`、state 保持 `{ from: '/flags?page=2', fromLabel: '功能开关' }`，返回导航仍为「功能开关」并可回到带 `page=2` 的列表；
  - 评估页从详情进入时横幅 POP 并保留原来源；
  - 切换 Flag 后横幅指向新 Flag 并以「规则评估」为来源 push。
- `npx tsc --noEmit` 通过；`npm run build` 通过。
- Playwright 真实浏览器 13 项全部通过，新增 2 项：功能开关来源与全局操作历史来源的详情 → 评估 → 详情往返均保留标签并能回到原页面。
