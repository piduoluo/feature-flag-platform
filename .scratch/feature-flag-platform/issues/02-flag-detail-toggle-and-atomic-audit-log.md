# 02: Flag 详情、基本信息修改、一键启停与原子操作历史

**What to build:**
配置管理员和运维人员可以在前端点击查看 Flag 的详细信息（基础信息、生效环境、启停状态、默认返回值、创建与更新时间），能够在线编辑 Flag 的名称、描述与默认返回值，并可通过详情页或列表页的一键开关（Switch）对 Flag 进行毫秒级启用与停用切换。系统在同一个数据库事务中原子记录每次创建、修改与启停行为至操作历史（Audit Log），用户可在操作历史面板中按时间倒序追溯每一次变更明细。

**Blocked by:** 01: Monorepo 基础脚手架与 Flag 列表及创建

**Status:** ready-for-agent

- [ ] 配置管理员能够查看 Flag 的详细信息卡片与基础属性
- [ ] 配置管理员能够编辑 Flag 的基本信息（名称、描述、默认返回值）并保存生效
- [ ] 运维人员能够在前端一键切换 Flag 的启用或停用状态，带有直观的加载反馈
- [ ] 系统记录 Flag 的创建（FLAG_CREATED）、基本信息修改（FLAG_UPDATED）及启停切换（FLAG_TOGGLED）操作历史
- [ ] 业务变更与 Audit Log 在单一数据库显式事务内原子提交，任何一方失败全量回滚
- [ ] 操作历史面板按时间倒序展示发生时间、操作类型、固定操作者及变更摘要
- [ ] 自动化测试覆盖业务变更与审计记录的事务原子性回滚以及启停状态切换
