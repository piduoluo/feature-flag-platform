# 08: 前端与业务契约对齐

**Type:** task
**Status:** resolved
**Blocked by:** None

## Goal

移除没有后端能力或业务文档依据的前端入口，并修复前端在严格 JSON 数值、规则优先级、分页筛选、状态说明和刷新行为上与现有 Go API 契约不一致的问题。后端接口、字段和数据库约束保持不变。

## Acceptance

- [x] 顶部仅显示 `FeatureFlag`，不再显示未经确认的平台、厂商和版本包装。
- [x] 删除虚假用户菜单和只作用于当前页的启停筛选入口。
- [x] 规则配置与在线评估可无损处理后端支持的大整数 JSON 数值。
- [x] 规则优先级保留唯一正整数语义，不再自动压缩为连续序号。
- [x] Flag 停用、默认回退、布尔结果与新建默认状态的文案符合 SPEC。
- [x] 评估 Flag 候选通过现有搜索接口按需加载，返回入口与当前选择一致。
- [x] 同页修改成功后刷新变更历史；复制操作只在成功后提示成功。
- [x] 删除业务文档未规定的描述 500 字前端限制。
- [x] 前端测试、构建与必要的真实页面验证通过。

## Answer

前端已按现有业务文档和 Go API 契约完成收敛，未修改后端接口、字段、校验或数据库约束。删除无后端能力支撑的用户菜单与启停筛选；统一顶部品牌为 `FeatureFlag`；补齐无损 JSON 数值、显式优先级、远程 Flag 搜索、动态返回入口、状态语义、审计刷新和复制失败处理。

验证结果：前端 13 个测试文件共 108 项测试通过；TypeScript 与 Vite 生产构建通过；Docker 前端镜像重建成功，并在真实页面确认列表筛选移除、停用 Flag 说明、规则优先级和评估返回入口。
