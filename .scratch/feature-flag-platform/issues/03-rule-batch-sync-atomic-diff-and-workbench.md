# 03: 规则批量同步、原子 Diff 审计与规则配置工作台

**What to build:**
产品经理与配置管理员可以在 Flag 详情页的规则配置工作台中，为 Flag 维护多条基于数值优先级（正整数，1 为最高优先级）的有序灰度规则。用户可以配置属性名、操作符（equals 与 in）、期望值及命中返回值，并能自由增删、调整单条规则或进行优先级原子互换（Swap）。所有规则变更通过单次批量提交保存，后端自动计算精确的三向差异（新增、修改、删除），并在同一数据库事务中原子同步规则表并记录 RULES_SYNCED 审计日志。若内容无任何变动则自动跳过审计写入；清空全部规则前必须进行前端二次确认，清空后正确生成包含删除明细的审计记录。

**Blocked by:** 02: Flag 详情、基本信息修改、一键启停与原子操作历史

**Status:** ready-for-agent

- [ ] 产品经理能够为 Flag 配置多条有序匹配规则（属性名、equals/in 操作符、期望值、布尔返回值及正整数优先级）
- [ ] 前端与后端严格拦截同一 Flag 下的重复优先级（PRIORITY_CONFLICT）及非法正整数校验（VALIDATION_ERROR）
- [ ] 支持规则优先级的原子互换（Swap，如规则 A 与规则 B 互换次序），更新过程中不触发瞬时唯一索引冲突
- [ ] 批量保存接口在单事务内比对原规则与新规则，精确持久化变更并写入包含新增、修改、删除差异的 RULES_SYNCED 审计记录
- [ ] 当提交的规则内容与排序完全无变动时，系统静默跳过审计日志写入，不产生空白审计记录
- [ ] 提供清空规则功能，前端执行二次确认弹窗防误触，提交后安全删除全部规则并产生包含完整 deleted 差异的审计日志
- [ ] 校验规则 ID 全量归属于当前 Flag 且请求内无重复 ID，杜绝跨 Flag 篡改
- [ ] Flag 详情接口与规则同步接口均返回按优先级严格升序排列的规则列表
- [ ] 自动化测试覆盖三向 Diff 计算准确性、优先级互换无冲突、重复优先级拦截、空规则清空契约与空白审计抑制
