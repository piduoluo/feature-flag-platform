# 06: 前端响应式布局与表格溢出修复

**What to build:**
修复共用侧栏、Flag 列表、全局操作历史、在线评估控制台和 Flag 详情页在 390、768、1024、1440px 宽度下的排版问题。保持现有业务操作和数据展示。

## Answer
