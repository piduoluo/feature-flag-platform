Type: task

## Goal

沿用现有橙色主题，将评估结果重排为摘要、真实决策链路、下一步操作；后端补充逐条规则解释。

## Acceptance

- 评估响应提供 flag_id、default_value、rule_count、rule_trace；保持三态、严格类型、精度和短路行为。
- 页面展示实际执行步骤，区分缺失/null/类型/值差异；复制本次请求，正确跳转详情 Tab。
- 输入变化使旧结果失效，过期请求不得覆盖新输入；旧后端无明细时明确提示。
- 后端/前端测试及构建通过，真实 API 在 1440/1024/390px 验证。
- 不改变演示数据，不新增数据库表或依赖。

## Answer

- 评估引擎在同一次求值中产出 `rule_trace`，补充 `flag_id`、`default_value`、`rule_count`；新增 `ATTRIBUTE_MISSING`、`NULL_VALUE`、`TYPE_MISMATCH`、`VALUE_MISMATCH`、`NOT_IN_SET`、`INVALID_RULE`、`MATCHED` 稳定原因枚举。首条命中后停止，停用与无执行规则返回空数组，严格类型、大整数精度和短路结果不变。
- 评估页右侧按“结果摘要 → 决策链路 → 下一步”重排，逐条展示实际值、期望值与未命中原因，并区分属性缺失、显式 null、类型和值差异；保留绿色命中、灰色普通未命中、琥珀色停用语义。
- 操作区通过响应中的 `flag_id` 进入规则/默认值 Tab，复制与右侧解释绑定同一次提交；输入变化会清空结果并使在途请求失效。旧响应缺少链路时只展示摘要并提示明细不可用。
- 后端测试覆盖全部原因、排序、首条命中返回 false、停用、空规则、大数字精度与 HTTP 字段；前端 144 项测试、生产构建、Docker 构建通过。
- 真实 API 验证 `US/free` 回退默认值，`CN/premium` 在第 2 条命中并停止；1440/1024/390px 无整页横向溢出，长 JSON 值正常换行。复制、规则/设置 Tab 跳转和过期响应已在真实浏览器确认，localhost:3000 已更新。
- 未新增数据库表或依赖，未修改演示 Flag 与规则数据。
