# 09: 产品 Logo 与侧栏折叠交互

**Type:** task
**Status:** resolved
**Blocked by:** None

## Goal

使用用户提供的真实产品 Logo，并修复桌面侧栏折叠态的展开入口：默认仅显示 Logo，光标移入 Logo 区域时在同一位置显示展开按钮。

## Acceptance

- [x] 桌面侧栏与移动端导航使用用户提供的真实 Logo。
- [x] 折叠侧栏默认仅显示 Logo。
- [x] 光标移入 Logo 区域时，Logo 在原位切换为展开按钮。
- [x] 键盘聚焦展开按钮时保持可见。
- [x] 展开态的折叠按钮和移动端导航行为保持可用。
- [x] 聚焦测试、构建和真实页面验证通过。

## Answer

已将用户提供的 PNG 原样加入前端资源，并替换桌面侧栏和移动端导航中的临时旗帜图标。折叠态使用与 Logo 同尺寸、同位置的覆盖式展开按钮：默认 Logo 可见；Logo 区域悬停或按钮获得键盘焦点时，Logo 淡出、展开按钮淡入；离开后恢复 Logo。

验证结果：源文件与仓库资源 SHA-256 一致；AppShell 3 项聚焦测试通过；TypeScript 与 Vite 生产构建通过；Docker 前端镜像重建成功；真实页面已验证展开态、折叠默认态、Logo 悬停态和展开操作。
