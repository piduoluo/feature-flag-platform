# 29: Flag 详情「基本设置」布局与信息层级

Type: task
Status: resolved

## Goal

复查 Flag 详情「基本设置」的整体布局与信息层级：让表单容器与内容宽度匹配，按「标识信息 / 评估默认值」建立视觉分组，并移除默认返回值下方的描述性小字。

## Acceptance

- [x] 基本设置不再是一张 1136px 宽的卡片里漂着 600px 表单：桌面端卡片收窄为 760px 的聚焦宽度，字段占满卡片内容区。
- [x] Flag 名称、描述归为「基本信息」组；默认返回值用细分隔线与上组分开，保存操作保持在表单底部。
- [x] 删除「默认返回值」下方「持久化配置值（即配置默认值）：未命中规则时生效；……」的长段灰色小字。
- [x] 页面头部 meta 行仍保留当前生效语义（未命中规则时返回该值 / 停用期间评估始终返回 false），信息不丢失。
- [x] 移动端（390px）卡片内边距收敛为 20px / 16px，表单无横向溢出。
- [x] 单测断言旧小字不再出现；前端全量测试、`tsc --noEmit`、生产构建与真实浏览器回归通过。

## Answer

**布局与层级**

- settings Tab 的 `Card` 从全宽 + `padding: 8px 0` 改为 `.detail-settings-card`：桌面最大宽度 760px，内边距 28px / 32px，圆角与详情头部统一为 9px。
- 表单去掉 `maxWidth: 600`，改为占满卡片内容区（桌面约 696px），名称/描述输入框与卡片边界形成统一的阅读栏。
- 名称 + 描述之后加入 `.detail-settings-divider` 细分隔线，把「基本信息」与「默认返回值」分成两个视觉组；保存按钮仍在表单末尾。
- 窄屏（≤700px）卡片内边距降为 20px / 16px，390px 下字段、Tab 与保存按钮均在视口内。

**移除小字**

- 删除 `默认返回值` Form.Item 的 `extra` 长段说明，表单内只保留字段标签与控件。
- 停用/默认值语义仍由详情页头部 meta 行承载：启用时显示「未命中规则时返回该值」，停用时显示「停用期间评估始终返回 false」，并继续展示配置默认值。
- `FlagDetailPage.test.tsx` 增加回归断言：`持久化配置值` 不再渲染。

**验证**

- 前端 14 个测试文件 148 项通过；`tsc --noEmit` 与 `npm run build` 通过。
- Playwright 真实浏览器 13 项通过；1440px 与 390px 截图核对卡片宽度、分组、字段与保存按钮位置。
- 已重建前端镜像，localhost:3000 为最新布局。
