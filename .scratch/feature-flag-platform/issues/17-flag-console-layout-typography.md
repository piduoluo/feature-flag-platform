# 17: 功能开关页整体布局与字体优化

**Type:** task
**Status:** resolved
**Blocked by:** 14, 15, 16

## Goal

按用户授权自主优化当前功能开关页的信息层级、布局比例与字体。沿用橙色操作强调、白底和现有侧栏，提升日常查找、比较和操作 Flag 的效率。

## Acceptance

- [x] 标题、辅助说明、状态统计权重有明确区分。
- [x] 常见桌面宽度下环境筛选与搜索操作保持稳定对齐，窄容器有明确重排。
- [x] 名称、Key、状态、默认值与更新时间有一致的字体角色和合理密度。
- [x] 宫格身份信息与配置元数据分组清晰，Key 获得足够空间。
- [x] 原有菜单、筛选、分页、启停、新建与视图切换继续可用。
- [x] 前端定向测试、构建、桌面及移动端实际页面检查通过，并更新 localhost:3000。

## Design

- 主阅读顺序：页面身份 → 筛选与操作 → Flag 名称与运行信息 → 辅助时间及分页。
- 标题 28px、名称 16px、正文/操作 14px、Key/元数据 13px；采用现有系统中文无衬线与代码等宽字体。
- 页面区块采用 32 / 24px 间距；关联内容采用 8 / 12 / 16px 间距。统计退为紧凑筛选，操作栏统一 40px 高。
- 布局按内容容器宽度重排；列表在自身容器滚动，宫格在窄屏变为单列。

## Answer

- 收敛标题和统计的字号与面积；状态筛选增加明确选中态。工具栏以 CSS Grid 对齐，按内容容器宽度重排，避免侧栏展开时挤压或随意换行。
- 列表标题 28px、名称 16px、Key 与时间 13px、常规数据 14px，表头 44px、行高约 88px；信息列比例、行尾开关和更多操作统一对齐。
- 宫格以名称/Key 组成身份区；环境、启停、默认值、日期组成双行配置区。移除 Key 行的挤压与额外竖线，使用轻边框而非大片阴影。
- 表格与宫格共用分页组件；语义、API 和 URL 处理沿用现有实现。
- 21 项列表与宫格相关测试通过；本机与容器生产构建通过；Impeccable 检测返回空结果；`git diff --check` 通过。
- 两轮浏览器检查覆盖 1440px 桌面、1024px 中等宽度及 390px 手机，包含真实长名称、12 条记录、侧栏展开/折叠和两种视图。最终检查中页面宽度未超过视口，手机卡片内容宽度等于自身可用宽度；列表横向滚动限制在表格内部。
- 已重新构建并启动前端容器；localhost:3000 提供的 JS/CSS 与本次验证的构建产物逐字节一致。截图保存于 `output/playwright/flag-layout-*.png`。
