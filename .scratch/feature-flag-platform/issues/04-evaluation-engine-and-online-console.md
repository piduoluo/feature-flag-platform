# 04: 确定性有序评估引擎与在线评估控制台

**What to build:**
调用方服务与测试人员可以通过在线评估控制台或评估 API，传入 Flag Key、环境以及包含用户属性的 JSON 上下文发起评估。系统内部纯内存领域评估引擎负责按规则优先级升序逐条判定，首条命中立即短路返回；当 Flag 被停用时立即返回 false（FLAG_DISABLED）；当所有规则均未命中时回退至 Flag 默认值（DEFAULT_FALLBACK）。规则匹配执行严格类型隔离与精确数值比对（1 与 1.0 相等、大整数无精度损失、严禁跨类型匹配，null 或缺失属性安全跳过）。在线控制台提供实时 JSON 语法高亮校验与格式错误拦截，并以三种显式视觉状态卡片清晰展示最终结果与命中规则明细。

**Blocked by:** 03: 规则批量同步、原子 Diff 审计与规则配置工作台

**Status:** ready-for-agent

- [ ] 调用方可通过 API 传入 flag_key、environment 及 context 属性对象发起评估
- [ ] Flag 处于停用状态时，评估始终强制返回 false 且 reason 标识为 FLAG_DISABLED，不执行规则计算
- [ ] 评估引擎严格按 priority 升序逐条匹配，首条命中时立即短路返回，reason 标识为 RULE_MATCH 并包含命中规则元数据
- [ ] 所有规则均未命中时，系统返回 Flag 的默认布尔值，reason 标识为 DEFAULT_FALLBACK
- [ ] equals 操作符执行严格 JSON 标量比对与精确数值匹配（1 等于 1.0，大整数无精度丢失；严禁跨类型自动转换如 1 != "1"、true != "true"）
- [ ] in 操作符执行严格标量数组包含匹配，禁止空数组或包含非标量元素
- [ ] 用户上下文中属性缺失或取值为 null 时，当前规则判定为不命中并平滑继续评估后续规则
- [ ] 在线评估控制台支持环境选择、Flag 检索与 JSON 属性输入，具备实时 JSON 语法校验与错误提示
- [ ] 控制台结果区以鲜明的三态视觉卡片呈现评估结论（规则命中展示绿色成功态与规则明细、默认回退展示中性提示态、停用展示警示态）
- [ ] 表格驱动自动化测试全面覆盖类型隔离、数值比对、边界 null、大整数、短路求值与状态回退逻辑
