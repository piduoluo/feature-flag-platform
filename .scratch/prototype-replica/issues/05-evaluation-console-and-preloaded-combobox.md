# 05: 规则评估控制台双栏交互与 Flag 预载 1:1 落地

**What to build:** 完整移植原型的「规则评估控制台」左右双栏布局。支持根据选择的环境动态预载 Flag 列表，提供 Flag Key 组合输入框（Combobox）实时搜索与展示；Context JSON 具备实时语法校验、行号精确定位、错误红框/警示卡片及辅助工具栏；右栏真实呈现决策链路与三态决策卡片。

**Blocked by:** 01: 视觉设计系统与 AppShell 框架 1:1 落地

**Status:** resolved

- [x] 顶部操作区提供「管理 Feature Flags」按钮，点击平滑返回 Flag 列表页。
- [x] 评估输入面板（左栏）1:1 移植：
  - 生效环境（Environment）下拉单选（Dev / Staging / Prod），切换环境时自动异步调用后端 `GET /api/v1/flags?environment={env}&page_size=100` 预载该环境下的 Flag 列表；
  - 右侧提示当前环境预载数量（如“已预载当前环境 3 个 Flag”）；
  - 特性开关标识（Flag Key）采用 Combobox 组件，点击或输入时弹出下拉菜单展示匹配的 Flag Key、名称与启停状态徽标（已启用绿色 / 已停用灰色），同时允许用户自由手动输入任何自定义 Flag Key；
  - Context JSON 输入区上方提供辅助工具栏：「格式化」按钮（语法有效时可用）、「示例」填充按钮与「清空」按钮；
  - Context JSON 实时校验：右上角展示状态徽标（空上下文 / JSON 格式有效 / JSON 格式错误），输入错误时文本框红框高亮，并在下方错误槽位渲染“JSON 语法错误（第 X 行）”及错误详情 Alert；
  - 底部「发起在线评估」主按钮带播放图标，在 Flag Key 为空或 JSON 语法错误时自动禁用，点击后展示 Loading 态，并支持 `Cmd/Ctrl + Enter` 快捷键提交。
- [x] 评估结果面板（右栏）1:1 移植三态决策渲染：
  - 初始态展示居中收件箱图标与操作引导文案；
  - 评估中展示轻量 Spinner 与“正在执行领域评估引擎规则匹配...”加载态；
  - 评估失败（如 Flag 不存在）在结果区顶部渲染“评估调用失败”警示条，支持关闭；
  - 熔断态（`FLAG_DISABLED`）：渲染琥珀色面板，解释特性开关已停用与安全熔断机制，结果数值卡片展示加粗红色 `false` 与“已熔断 / 强制关闭”标签；
  - 规则命中态（`RULE_MATCH`）：渲染绿色面板，解释短路求值机制，结果数值卡片展示 `true`（功能放量开放）或 `false`（特定限制关闭），下方嵌套结构化「命中规则明细」表格（优先级、返回值、属性名代码气泡、操作符、期望值 JSON）；
  - 回退默认值态（`DEFAULT_FALLBACK`）：渲染蓝色面板，说明未命中任何规则回退至默认返回值，结果数值卡片展示对应布尔值与“未命中规则 · 回退默认”标签。
