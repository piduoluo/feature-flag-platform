# 01: 视觉设计系统与 AppShell 框架 1:1 落地

**What to build:** 为平台建立与独立原型 1:1 完全一致的全局视觉底座与 AppShell 架构。包含全套 Design Tokens（`--brand: #ff7d41` 滴滴品牌橙、`--canvas`、`--surface` 等所有样式变量）、顶部 2px 品牌标识线、侧边栏 256px / 72px 桌面端折叠展开（折叠态悬停 Logo 浮现展开控件）、移动端抽屉遮罩、顶部面包屑与管理员头像下拉菜单、全局居中 Toast 消息流与 `[data-tip]` 悬浮提示。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 页面引入原型的完整 Design Tokens（`--brand: #ff7d41; --canvas: #f6f6f4; --surface: #ffffff;` 等所有颜色、阴影、圆角变量），`body::before` 渲染固定 2px 滴滴橙顶条。
- [x] 侧边栏桌面端支持 256px 展开与 72px 折叠，包含滴滴品牌 Logo 图片与「Feature Flag」标识；折叠时悬停 Logo 区域能平滑显示展开按钮。
- [x] 导航栏提供「功能开关」、「规则评估」、「全局操作历史」三个菜单项，激活态具有橙色指示条与高亮背景，底部展示「滴滴研发工具 v1.0」。
- [x] 移动端（屏幕宽度 < 980px）侧边栏自适应收起，顶部展示汉堡菜单按钮，点击后滑出全高侧边导航并带有暗色背景遮罩。
- [x] 顶部栏左侧展示层级上下文（`研发平台 / Feature Flag`），右侧展示管理员头像 `AD` 与名称 `admin`，点击展开包含「个人设置」与「退出登录」的下拉菜单。
- [x] 建立全局居中 Toast 消息容器（支持最多 3 条堆叠、带成功/错误/信息图标及平滑动画）。
- [x] 实现 `[data-tip]` 属性的暗色精细悬浮气泡（Tooltip），支持屏幕边界防溢出定位与全局事件委托。
- [x] 现有路由与页面渲染保持平稳运行，无控制台错误。
