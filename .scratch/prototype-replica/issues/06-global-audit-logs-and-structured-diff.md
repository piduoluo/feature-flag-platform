# 06: 全局操作历史与结构化差异可视化 1:1 落地

**What to build:** 完整移植原型的「全局操作历史」表格与结构化差异可视化体系。包含多维度组合筛选工具栏、行首 `+`/`-` 展开明细控制、Flag Key 一键下钻至详情工作台变更历史 Tab，以及四种典型变更类型的结构化 Diff 卡片渲染（Flag 详情页变更历史 Tab 同步复用该 Diff 渲染能力）。

**Blocked by:** 01: 视觉设计系统与 AppShell 框架 1:1 落地

**Status:** resolved

- [x] 顶部工具栏移植：包含运行环境筛选下拉、操作类型筛选下拉（全部/创建 Flag/修改基本信息/启停切换/规则批量同步）、Flag Key 搜索框，以及右侧「共 X 条记录」计数展示。
- [x] 操作日志表格样式 1:1 对齐：
  - 行首提供展开按钮（`.expand-btn`），展示精细的 `+` / `-` 状态切换；
  - Flag Key 列展示代码按钮，点击一键跳转至 `/flags/:id/audit` 详情变更历史 Tab；
  - 运行环境展示对应环境标签；
  - 动作列展示灰色小圆点与对应的中文动作标签；
  - 操作人与格式化时间（`YYYY/MM/DD HH:mm:ss`）。
- [x] 展开行（`.audit-detail`）结构化 Diff 精确解析与渲染：
  - `FLAG_CREATED`（创建 Flag）：以双列名值对（`.diff-created`）展示 Flag Key、名称、环境、默认返回值与初始规则数；
  - `FLAG_TOGGLED`（启停切换）：以流转标记（`.diff-toggle`）展示“已启用/已停用 → 已启用/已停用”；
  - `RULES_SYNCED`（规则批量同步）：分为“新增规则”、“修改规则”、“删除规则”三个独立子区块（`.diff-section`），新增与删除展示完整规则快照，修改展示字段级别的“旧值 → 新值”高亮对比；种子同步展示数量说明；
  - `FLAG_UPDATED`（修改基本信息）：展示名称/描述/默认返回值的前后取值对比条；
  - 异常或格式不完整时优雅降级并展示友好提示，永不发生白屏崩溃。
- [x] Flag 详情页 Tab 2「变更历史」时间轴卡片同步采用相同的 Diff 解析与组件渲染，保持视觉规范高度统一。
- [x] 底部提供规范的翻页器（上一页/下一页、数字页码按钮与 10/20/50 条数选择），与后端分页真实联动。
