# 03: Flag 详情工作台与规则引擎 1:1 落地

**What to build:** 完整移植原型的 Flag 详情页顶部概览看板与 Tab 1「规则配置」工作台。支持有序规则序号卡片流、原子重排上移/下移、添加与编辑规则 Modal、删除单条规则与清空全部规则的二次确认 Modal、已生效默认返回值展示卡片、以及底部吸底保存浮层。

**Blocked by:** 01: 视觉设计系统与 AppShell 框架 1:1 落地

**Status:** resolved

- [x] 顶部概览看板展示 Flag 显示名称、运行环境标、带复制按钮的 Flag Key、最后更新时间、规则总数、已生效默认返回值与「前往在线评估」按钮。
- [x] 顶部行内启停 Switch 开关与真实 `PATCH /api/v1/flags/:id/toggle` 接口绑定，防重与错误回滚。
- [x] Tab 导航栏展示「规则配置」、「变更历史」、「基本设置」，当规则或基本设置存在未保存草稿时，对应 Tab 标题右侧展示橙色星号（`*`）脏状态指示器。
- [x] 规则配置工作台展示工具栏：「添加规则」按钮与「清空全部规则」危险按钮（规则为空时禁用）。
- [x] 规则以卡片流（`.rule-card`）展示：
  - 卡片头部展示规范的两位序号（`规则 01`、`规则 02`）；
  - 卡片主体展示条件摘要（属性名加粗、操作符蓝色标签、期望值 JSON 代码块、命中返回值提示）；
  - 操作按钮组包含「上移」、「下移」（首项禁用上移，末项禁用下移）、「编辑规则」与「删除规则」危险按钮。
- [x] 添加/编辑规则 Modal：包含属性名输入、操作符选择（`equals` / `in`）、期望值 JSON 文本域（执行严格的 JSON 标量/数组格式与安全整数校验）与命中返回值 Switch；确认后将变更存入规则内存草稿。
- [x] 删除单条规则与清空全部规则弹窗：点击弹出原型原生的确认对话框（当规则仅剩 1 条或执行全部清空时，提示“清空后所有流量将回退为默认返回值，此改动将在保存后生效”），确认后仅更新本地草稿。
- [x] 底部展示「默认返回值（已生效）」卡片，当基本设置中有未生效的默认值草稿时，额外渲染警示黄条（Alert）。
- [x] 当本地规则草稿与服务端数据不一致时，页面底部浮现吸底操作栏（`.dirty-bar`），展示“规则配置有未保存修改”小圆点与“放弃修改”、“保存规则配置”按钮；点击保存调用真实 `PUT /api/v1/flags/:id/rules` 提交，成功后关闭脏状态并触发 Toast。
