# 04: 基本设置独立表单与跨页/评估未保存卫视 1:1 落地

**What to build:** 完整移植原型的 Tab 3「基本设置」独立表单与全域未保存草稿状态机防护。涵盖离开当前 Flag 时的路由拦截确认弹窗、前往在线评估时的保存/放弃拦截弹窗、以及关闭浏览器标签时的 `beforeunload` 原生防护。

**Blocked by:** 03: Flag 详情工作台与规则引擎 1:1 落地

**Status:** resolved

- [x] Tab 3 基本设置展示独立表单：包含 Flag 名称输入框（必填校验）、描述多行文本域、默认返回值 Switch 开关，以及「保存设置」主按钮。
- [x] 当基本设置草稿与服务端数据完全一致时，「保存设置」按钮保持禁用；有实质性改动时高亮启用，点击后调用 `PUT /api/v1/flags/:id` 独立保存，保存成功后清除脏标记并弹出 Toast。
- [x] 切换详情页内部 Tab（规则配置 / 变更历史 / 基本设置）时，两处草稿互不影响且静默保留。
- [x] 跨页离开拦截弹窗（`leave-detail`）：当规则或基本设置存在未保存草稿时，点击侧边栏或其他路由链接触发弹窗（标题“离开当前 Flag？”，正文说明“离开将丢弃未保存的基本设置与规则草稿。”），提供“继续编辑”与“放弃修改并离开”选项。
- [x] 前往在线评估拦截弹窗（`eval-unsaved`）：当存在未保存草稿时，点击概览区的“前往在线评估”触发弹窗（正文罗列“未生效数据域：基本设置、规则配置”），提供三个操作选项：
  1. “继续留在本页编辑”：取消弹窗留在原处；
  2. “放弃修改并前往”：清空所有草稿，直接跳转评估页并携带该 Flag 上下文；
  3. “保存并前往”：按“基本设置先于规则”的严格次序调用真实后端 API 保存，若基本设置校验失败（如名称为空），自动切回基本设置 Tab 并聚焦错误输入框，不发生跳转。
- [x] 页面刷新或关闭标签页时，绑定浏览器原生 `beforeunload` 告警，防止意外丢失配置。
