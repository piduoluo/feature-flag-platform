# 02: Flag 列表页双视图与新建抽屉 1:1 落地

**What to build:** 完整移植原型的 Flag 列表页工具栏、列表 (Table) 与宫格 (Grid) 双重视图切换、行操作气泡菜单以及新建 Flag 抽屉。所有数据加载与操作均对接真实 Go API，支持实时搜索、运行环境筛选与启停状态筛选。

**Blocked by:** 01: 视觉设计系统与 AppShell 框架 1:1 落地

**Status:** resolved

- [x] 顶部工具栏 1:1 复刻原型：包含搜索框（带搜索图标、清除按钮及回车即搜）、运行环境下拉选择（全部/Dev/Staging/Prod，带选中打勾状态）、启停状态筛选按钮与浮层菜单、列表/宫格视图切换按钮组、刷新旋转按钮与「新建 Flag」橙色主按钮。
- [x] 列表视图（Table）完整对齐：
  - Flag Key 列展示代码气泡（code-chip）及复制按钮，点击即时触发 Toast；
  - 名称与描述展示完整层级，描述超长支持省略截断；
  - 运行环境展示对应环境标签（dev 蓝色、staging 琥珀色、prod 洋红色）；
  - 启停状态展示指示圆点与「已启用/已停用」文字；
  - 默认返回值展示对应 `true` / `false` 标签；
  - 更新时间拆分为日期与具体时间双行排版；
  - 操作列展示「详情」直达按钮与「...」更多操作按钮，点击弹出气泡菜单支持「在线评估」下钻与「启用/停用 Flag」快捷切换。
  - 点击表格行可直接进入 `/flags/:id` 详情工作台。
- [x] 宫格视图（Grid）完整对齐：卡片网格响应式排版，展示 Flag 标识、快捷评估按钮、Key 代码、名称描述、环境标签与启停状态、默认返回值、更新时间与行内 Switch 切换开关。
- [x] 自定义底部翻页栏：展示总记录数、上一页/下一页、数字页码按钮及「10 条/页、20 条/页、50 条/页」下拉选择，与后端分页真实联动。
- [x] 新建 Flag 抽屉（Drawer）1:1 移植：
  - 右侧滑出面板，包含环境选择、Flag Key、名称、描述（带 `0 / 500` 动态字数统计）与默认返回值 Switch 开关；
  - Flag Key 支持客户端格式校验（字母、数字、下划线、连字符）与超长拦截；
  - 捕获后端 409 `FLAG_KEY_CONFLICT` 错误并在顶部渲染原型的警示红条（Alert）；
  - 点击创建展示 Spinner 加载态并防重复提交，创建成功后收起抽屉并刷新列表。
