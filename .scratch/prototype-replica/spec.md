# 1:1 复刻前端效果规范说明 (Prototype Replica Spec)

## 1. 背景与目标
基于提供的独立前端高保真交互原型（`Feature Flag · 灰度规则平台`），在现有 Vite + React 18 + TypeScript + Ant Design Monorepo 体系下，进行 1:1 像素级视觉与交互复刻。

该前端原型已针对现有业务逻辑与数据进行了一次对齐，但可能存在字段命名或 API 契约细节差异。本次工程落地的核心目标是：
1. **视觉与交互 1:1 像素级还原**：移植全部 Design Tokens（`--brand: #ff7d41` 滴滴橙、`--canvas`、`--surface` 等）、侧边栏 256px/72px 桌面端折叠切换、移动端遮罩、顶部全局 Toast 浮层流与 Tooltip 规范。
2. **零 Mock 降级，100% 对接 Go 后端**：所有状态变更（Flag 创建、启停切换、基本设置保存、规则原子批量同步、在线评估、全局审计查询）均真实调用 Go REST API 并持久化至 PostgreSQL。
3. **保证质量防线与测试全绿**：确保前端现有的 91 个 Vitest 单元/集成测试与 Playwright 端到端 Smoke 测试 100% 通过。

## 2. 关键架构与模块规范

### 2.1 Design System & AppShell
- **Tokens**: `--canvas: #f6f6f4; --surface: #ffffff; --brand: #ff7d41; --green: #168653; --red: #c2403a; --amber: #a2650f; --blue: #3f6b97; --purple: #70518f;`
- **品牌顶条**: `body::before { height: 2px; background: var(--brand); }`
- **Logo 与折叠**: 侧边栏桌面端支持展开（256px）与折叠（72px），折叠态悬停 Logo 浮现展开控制图标；移动端（<980px）采用滑出抽屉与半透明遮罩。
- **顶部栏**: 面包屑上下文 `研发平台 / Feature Flag`，右侧 `AD` 管理员头像下拉菜单（视觉演示）。
- **浮层系统**: 顶部居中轻量 Toast 消息流（最多堆叠 3 条，淡入淡出动画），基于 `[data-tip]` 属性的暗色精细悬浮气泡。

### 2.2 Flag 列表页与新建抽屉
- **双重视图**: 支持 Table 列表视图与 Grid 宫格卡片视图平滑切换，状态持久化。
- **工具栏**: 搜索框（支持实时搜索与清除）、运行环境下拉勾选菜单（全部/Dev/Staging/Prod）、启停状态筛选下拉（全部/已启用/已停用）、刷新按钮动效、「新建 Flag」主按钮。
- **新建抽屉**: 右侧滑出抽屉，包含环境选择、Key 格式检查与唯一性校验（捕获后端 409 `FLAG_KEY_CONFLICT` 冲突）、名称/描述与字符计数器（`0 / 500`）、默认返回值 Switch 与创建 Loading/防重复提交。
- **操作行**: 列表操作列提供「详情」直达按钮，以及「...」更多气泡菜单（包含「在线评估」下钻与「启停切换」快捷开关）。

### 2.3 Flag 详情工作台与规则引擎
- **工作台概览**: 顶部展示 Flag 名称、环境色标、Key 复制小图标、最后更新时间、规则总数、已生效默认返回值标签、行内启停控制与「前往在线评估」按钮。
- **Tab 联动**: 规则配置（未保存带星号 `*`）、变更历史、基本设置（未保存带星号 `*`）。
- **规则工作台**: 序号卡片流（`规则 01`）、条件摘要、上移/下移原子重排、添加/编辑 Modal（支持安全整数及标量/数组校验）、清空全部规则二次确认 Modal、底部吸底保存栏（`.dirty-bar`）提供「放弃修改」与「保存规则配置」。
- **基本设置**: 独立表单提交（Flag 名称必填校验、描述、默认返回值 Switch），未变更时禁用保存按钮。
- **全域未保存卫视**: 离开 Flag 路由拦截弹窗（「离开当前 Flag？」），前往评估拦截弹窗（「前往评估前处理未保存修改」：继续留在本页编辑 / 放弃修改并前往 / 保存并前往）。

### 2.4 规则评估控制台
- **双栏布局**:
  - **左栏输入**: 环境切换自动预载当前环境 Flag 列表；Flag Key 组合输入框（Combobox）支持下拉过滤展示与自由输入；Context JSON 输入框支持语法实时校验、行号精准提取与错误提示卡片、一键格式化、示例填充与清空；「发起在线评估」按钮带 Loading 状态与快捷键。
  - **右栏决策**: 三态结果卡片——`FLAG_DISABLED` 熔断橙色面板、`RULE_MATCH` 绿色决策面板（带短路解释、放量标签及规则属性明细表）、`DEFAULT_FALLBACK` 蓝色回退默认值面板。

### 2.5 全局操作历史
- **工具栏**: 运行环境筛选、操作类型筛选、Flag Key 搜索框、总记录数计数。
- **表格与下钻**: 行首 `+`/`-` 展开收起按钮、Flag Key 按钮点击下钻至对应 Flag 的详情变更历史 Tab、环境色标、操作类型小圆点图标、操作人与格式化时间。
- **结构化 Diff**: 展开行精确展示创建快照名值对（`.diff-created`）、启停状态流转（`.diff-toggle`）、规则同步增删改卡片（`.diff-section` 新增规则/修改规则前后对比/删除规则快照）、基本信息修改字段前后比对（`.diff-changes`）。
