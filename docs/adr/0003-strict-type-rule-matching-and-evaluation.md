# 0003-strict-type-rule-matching-and-evaluation

## 上下文
规则评估引擎在比较用户属性与规则期望值时，存在弱类型自动转换（如字符串 "1" 与数字 1 相等）与严格强类型比对的权衡；在线评估控制台需要向使用者清晰解释评估结果来源。

## 决策
1. 期望值采用 JSONB 存储，执行严格类型比对：`equals` 仅当属性值与期望值类型一致且相等时命中；`in` 仅当期望值为数组且包含完全同类型同值的元素时命中；属性缺失或类型不匹配均判定为当前规则不命中，静默转入下一优先级规则。
2. 在线评估明确返回三种原因枚举：`FLAG_DISABLED`（Flag 停用拦截）、`RULE_MATCH`（命中特定规则）、`DEFAULT_FALLBACK`（未命中任何规则，回退默认值）。

## 原因与权衡
严格类型匹配消除了类型隐式转换带来的不可预知行为，保证跨环境、跨系统调用时的确定性；三态原因枚举直观解释了决策链路，避免了逻辑黑盒。
