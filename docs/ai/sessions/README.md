# 原始会话摘录（可选）

本目录用于存放从 AI 工具导出的关键会话片段。**当前交付未包含原始对话全文**，原因如下：

- 协作记录主要来自 Antigravity，另有部分任务分散在其他 AI 工具与终端代理中，未逐条导出；
- 原始会话体积大、包含大量中间尝试，全文归档会稀释评审注意力；
- 仓库内的工单（`.scratch/`）、提交（`git log`）、测试结果与截图已是可核对的主证据。

## 建议格式

每个主题一个 Markdown 文件，建议命名 `NN-<主题>.md`，单个文件不超过 100 行：

```markdown
# 会话摘录：<主题>

- 工具：Antigravity / 其他
- 日期：YYYY-MM-DD
- 关联工单：`.scratch/.../issues/NN-*.md`

## 任务 Prompt（原文或节选）

## AI 输出（关键片段）

## 人工判断与修正

## 结果与证据（提交 / 测试 / 截图）
```

## 整理规则

- 只保留能说明“任务 → 方案 → 纠正 → 结果”的片段，不贴完整对话。
- 删除账号、密钥、本地绝对路径等敏感信息。
- 引用时标注来源与日期；无法确认原文时注明“转述”，不虚构逐字内容。
