- **主力工具**：Antigravity，承担规格拆解、工单推进、代码实现与 UI 迭代。

## 怎么读

1. **只想确认过程真实**：看主日志的「时间线」与「AI 输出被纠正的记录」。
2. **想核对最终质量**：直接看 [`VERIFICATION_LOG.md`](./VERIFICATION_LOG.md)。
3. **想看原始任务轨迹**：按阶段进入 `.scratch/<工作流>/issues/`，每张工单都有目标、验收项与结论。
4. **想复现验证**：按验收日志中的命令执行；后端测试库的准备方式也在该文件里。

## 维护约定

- 主日志控制在 200 行以内，验收日志 150 行以内；新增内容优先放独立小节或 `sessions/`，不把原始对话整段贴入。
- 引用对话时标注来源（工单原文 / 用户指令 / 工具导出），不虚构逐字内容。
- 测试数量、提交号等易变信息，统一在最终验收时更新，并与 `VERIFICATION_LOG.md` 对齐。
